## 열거체 (혹은 열거형) (1)
- 열거체 혹은 열거형 (enumeration)이라고 하는 것은 변수가 가질 수 있는 값들을 미리 열거해 두어, 열거된 값들 외에는 변수에 대입할 수 없도록 한정해 둔 일종의 사용자 정의 자료형
- const 제한자와 비슷한 기능으로 기호 상수를 만드는 방법으로 사용할 수 있다
- 열거형 변수에는 정해진 값만 대입도리 수 있으므로 변수의 값이 실수에 의해 이상한 값이 들어가는 것을 방지할 수 있음.
- 열거형 정의
```c
enum 열거형_이름 {
    값1, 값2, ... ; // 열거자 : 정수 값을 나타내는 기호 상수를 나열
};
```

## 열거체 (혹은 열거형) (2)
(예)
```c
enum days { SUN, MON, TUE, WED, THU, FRI, SAT }; // 요일 days형 열거형의 정의
enum colors { black, brown, red, orange, yellow, green, blue, violet, gray, white }; // colors형 열거형의 정의
```
- 위에 정의된 days형 변수는 SUN, MON, TUE, ... SAT 중에서 하나의 값만을 가질 수 있다.
- 열거자들은 정수형이며 int형으로 처리된다.
- days 안에 들어있는 값 식별자들은 나열된 순서대로 컴파일러에 의해 0에서 시작하여 1씩 증가하는 것으로 자동으로 설정된다. 즉, SUN=0부터 1씩 증가하여 SAT=6이 된다.

## 열거체 (혹은 열거형) (3)
- 열거자들의 값들의 배정은 사용자가 식별자에 값들을 배정하여 변경할 수 있다.
(예)   
`enum days { SUN=1, MON, TUe, WEB, THU, FRI, SAT };`
    - 위와 같이 하면 식별자들의 값은 SUN=1부터 1씩 증가하며 SAT=7이 된다.
